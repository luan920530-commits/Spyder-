# NEURAL COMMAND // AI SPIDER OS

Plataforma académica modular **100% offline-first** con interfaz HUD cyberpunk ultraligera, visualización de grafos con física real (`D3.js v7`), esfera 3D de partículas (`KIMI-CORE`), cinemática en `HTML5 Canvas` y motor RAG local.

## Características Principales
- **Enjambre de 5 Arañas Cyber-Mech (`js/spiders.js`)**: Agentes especializados (`SPDR-01 DEF-AI`, `SPDR-02 CAUSAL-AI`, `SPDR-03 QUANT-AI`, `SPDR-04 SYNTH-AI`, `SPDR-05 CORE-AI`) con ciclo físico de 4 fases (`IR_A_PALABRA` → `EXTRAER_DATOS` → `ARRASTRAR_A_RED` → `ALIMENTAR_NODO`), mitosis automática/manual (1 a 5), Micro-IA local con aprendizaje en línea y monólogo metacognitivo.
- **Red Neuronal Viva (`js/neural-graph.js`)**: Esfera 3D `KIMI-CORE` de 220 partículas, filamentos sinápticos laterales, hubs maestros (`AGT-01` a `AGT-04`), fusión con refuerzo (`×2`, `×3`...), sinapsis cruzadas y **Live Pattern Ticker**.
- **Ingesta Universal y Paginación Anti-Saturación (`js/parsers.js`)**: Soporte local para `.pdf`, `.docx`, `.pptx`, `.xlsx`, `.txt`, `.md`, `.py`, `.js`, `.csv`, `.srt`, imágenes (OCR) y video (captura de fotogramas), renderizando únicamente la página activa (~1,600 caracteres).
- **Cerebro Conversacional `KIMI-CORE` (`js/brain-rag.js`)**: Recuperación híbrida `BM25` + expansión de grafo 1-salto + `TextRank` + evaluador matemático + generador de artefactos **HTML / PHP** desde la red neuronal + espacio **✍️ Redacción** colaborativa + puente opcional a Ollama (`localhost:11434`).
- **Persistencia Permanente (`js/store.js`)**: Almacenamiento local en `localStorage` + `IndexedDB` (`NeuralSpiderDB`).
- **Suite de Bots de Estudio (`js/study-bots.js`)**: Guía de Estudio editable (`.md`), Flashcards 3D, Quiz de Parcial con despacho visual de arañas y Exportador `.ZIP`.

## Ejecución Local
```bash
python3 -m http.server 8080
```
Luego abre `http://localhost:8080` en tu navegador.
